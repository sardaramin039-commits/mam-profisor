# پلانی ئەکادیمی بۆ پاراستنی دۆخی ئێستا و بەراوردکاریی گۆڕانکارییە گەورەکە

## پوختەی باری ئێستای سیستم (Baseline Snapshot)
لە ئێستادا تەواوی پایە سەرەکییەکانی سیستەمەکە تۆمار کراون:
1. **پەنجەرەی یەکەم و دووەم:** پەیوەندی و ناردنی دەستبەجێی بەشە ئەکادیمییەکان بۆ پەنجەرەی دووەم (`onSendToSecondWindow`).
2. **پێکهاتەی بەشەکان (Outline Architecture):** فایلی مۆدیولاری `src/app/helpers/outline-structure.ts` بۆ دروستکردنی داڕشتەی ئەکادیمی بەپێی ناونیشان و لاپەڕە.
3. **تەوەری هاندان و خاڵبەندی (Gamification Matrix):** هاوکێشەی خاڵبەندی، ٤ ئاستی ئەکادیمی (نۆفیز، شیکارکار، ڕەخنەگر، مامۆستای سەرپەرشتیار).
4. **تەوەری گێڕانەوە (Narrative Tension):** کاراکتەری دووەم (ڕەخنەگری دژبەر) و دووڕیانە مێژوویی و فیکرییەکان.
5. **سەقامگیری تەکنیکی:** پارێزراوی تەواوی تێکستە کوردییەکان، یاسای کەمتر لە ٥٠٠ دێڕ بۆ فایلە نوێیەکان، و سەوزبوونی تەواوی `ng lint`.

## هەنگاوەکانی جێبەجێکردن و بەراوردکردن

### قۆناغی ١: وەرگرتنی ڕەشنووس یان داواکاریی گۆڕانکارییە گەورەکە
- چاوەڕوانیی دەقی نوێ، پێکهاتەی نوێ، یان یاساکانی گۆڕانکاری لە بەکارهێنەر.
- پشکنینی کاریگەرییەکانی گۆڕانکارییەکە لەسەر بەشەکانی پێشوو.

### قۆناغی ٢: بەراوردکردنی ڕەخنەگرانە و زانستی (Comparative Matrix)
- دروستکردنی خشتەیەکی بەراوردکاری لە نێوان باری پێشوو (Current Baseline) و باری نوێ (Proposed State).
- شیکردنەوەی خاڵە بەهێزەکان، بۆشایییە شیاوەکان، و گونجانی لەگەڵ گوتاری زانستیی کوردیی سۆرانی.

### قۆناغی ٣: پاراستنی نەگۆڕەکان (Ironclad Code Preservation)
- پابەندبوون بە مەرجی نەگۆڕینی ڕووکاری بنەڕەتی مەگەر بە داواکاریی فەرمی.
- ئەنجامدانی گۆڕانکارییەکان بە شێوازی مۆدیولار لە پەڕگەی نوێدا بێ تێکدانی کۆدەکانی پێشوو.
- پشکنینی کۆتایی بە `lint_applet` و گەرەنتی بێ کێشەبوونی ئەپەکە.
