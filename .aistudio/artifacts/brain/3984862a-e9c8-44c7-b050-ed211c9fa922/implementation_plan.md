# پلانی ئەکادیمی بۆ پاراستنی دۆخی ئێستا و بەراوردکاریی گۆڕانکارییە گەورەکە

## پوختەی باری ئێستای سیستم (Academic Architectural Engines Suite)
سەرجەم پێنج پایە سەرەکییە ئەکادیمییەکە بە تەواوی جێبەجێ کراون و بە یەکترییەوە بەستراون:

1. **کالیبراسیۆنی ٤ ئاستە زانستییەکە (Level Calibration Profiles):**
   - **قوتابخانە (School):** ٢,٢٠٠ وشە، ٣ بەش، زمانی شیرین و سادە، بێ زاراوەی فەلسەفی، پێڕستی سادەی سەرچاوەکان لە کۆتایی ڕاپۆرتەکە.
   - **بەکالۆریۆس (Bachelor):** ١٢,٠٠٠ وشە، ٣ بەش، زمانی زانکۆیی ڕێکخراو، پێناسەی زاراوەیی و زمانەوانی، پەراوێزی ستاندارد.
   - **ماستەر (Master):** ٤٥,٠٠٠ وشە، ٣ بەش، شیکاری و بەراوردکاریی فرەقوتابخانەیی، پەراوێزی فرەزمانی بە ڕەنووسی کوردی.
   - **دکتۆرا (PhD):** ٩٠,٠٠٠ وشە، ٣ بەشی گەورە (تیۆری + پراکتیکی ١ + پراکتیکی ٢)، ٢٧ لق، پڕکردنەوەی کەلێنی مەعریفی (Knowledge Gap)، سەنتێزی نوێ و نەهێشتنی تەوەرەی هاوشێوە.

2. **تەلارسازیی نەخشەی ئەندازیاری (BlueprintAndOutlineAgent):**
   - مۆدێلەکانی `SubSectionPlan`, `SectionPlan`, `ChapterPlan`, و `AcademicBlueprint`.
   - دابەشکردنی هاوکێشەییانەی وشەکان بەپێی بودجەی تەرخانکراو.
   - مەرجی **`microTopicsToCover`** بۆ هەر لقێک تاوەکو ڕێگریی تەواو لە سووتانی کارتەکان (Content Cannibalization) و تێکەڵبوونی بابەتەکان بکرێت.
   - شیکاریی فرەڕەهەندی ناونیشان (`titleAnalysis`) و دەقی دەروازە و پوختەکان بە کوردی و ئینگلیزی (`frontMatterAndIntro`).

3. **بەڕێوەبەری سەرچاوە و پەراوێزی گونجێنەر (AdaptiveCitationManager):**
   - پێناسەی `SourceItem` بە ٤ زمانی ئەکادیمی (`ku`, `fa`, `ar`, `en`).
   - ڕەنووسی کوردی بۆ ژمارەکانی پەراوێز (٠ تا ٩).
   - بەڕێوەبردنی خۆکارانەی دووبارەبوونەوە بە جێگیرکردنی «(سەرچاوەی پێشوو)».
   - پۆلێنکردنی دوولایەنە: `simple_list` بۆ قوتابخانە، و بیبلۆگرافیای فرەزمانیی ٤ بەشی بۆ زانکۆ و خوێندنی باڵا بەپێی ئەلفوبێ.

4. **بزوێنەری نووسین و دیزاینی تایپۆگرافی (AdaptiveWriterAndDesigner):**
   - **`writeCalibratedSubSection`:** ئەجێنتی نووسینی لقەکان بە چەند قۆناغی پێکەوەبەستراو بەپێی سەقفی `maxWordsPerSinglePass`، پاراستنی گرێدانی پێچەوانەیی لەگەڵ لقی پێشوو و دانانی سنووری لقی داهاتوو.
   - **`generateCalibratedConclusion`:** ئەجێنتی نووسینی ئەنجام و ڕاسپاردەکان بەپێی کالیبراسیۆنی یاساکانی ئاستەکە.
   - **`generateLevelDesignStylesheet`:** بەرهەمهێنانی ستایلی تایپۆگرافی و چاپی کوردی (`@page`, `.academic-document-container`).

5. **بەڕێوەبەری گشتیی سەربەخۆ (MasterOrchestrator):**
   - **`generateCompleteAcademicWork`:** ئەنجامدانی پڕۆسەی کۆتایی لە سفرەوە تا سەد:
     1. داڕشتنی نەخشەی ئەندازیاری (Blueprint).
     2. نووسینی زنجیرەیی سەرجەم بەش و تەوەر و لقەکان بە Micro-Topics.
     3. نووسینی ئەنجام و ڕاسپاردەکان.
     4. کۆکردنەوەی بیبلۆگرافیای فرەزمانی و ستایلی چاپ.
   - دوگمەی ڕاستەوخۆ بۆ جێبەجێکردنی تەواوی بەرهەمەکە لەناو دەستکاریکەری دەستنووس (`EditorService`)، کۆپیکردنی دەقی تەواو و هەناردە.

6. **سەقامگیری تەکنیکی و بونیادی ئەپڵێت:**
   - بونیادی تەواو Zoneless بە ستانداردی Angular 21+.
   - تێپەڕبوونی ۱۰۰٪ پشکنینی تایپ‌سکریپت و کامپایل (`compile_applet: success`, dev server `200 OK`).
